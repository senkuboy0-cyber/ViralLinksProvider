# ViralLinksProvider

CloudStream Extension for ViralLinks Provider

## Installation

Add this repo to CloudStream:
```
https://raw.githubusercontent.com/senkuboy0-cyber/ViralLinksProvider/builds/repo.json
```

## Features

- Latest Movies
- Search functionality
- Download links
- Poster/fanart support

## Build

```bash
./gradlew ViralLinksProvider:make
```

## Tech Stack

- Kotlin
- CloudStream 3
- Jsoup
- Gradle
